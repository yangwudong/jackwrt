# 三方包：从作者的 GitHub 仓库下载，按 sha256 校验后加进镜像。
# 格式：<类型> <owner/repo> <tag 或 commit> <文件> <sha256> [tar 内路径 镜像内路径]
#   apk      Release 附件，是 .apk           → ImageBuilder packages/（参与依赖解析）
#   apk-tar  Release 附件，是含 .apk 的 tar.gz → 取出所有 .apk 放进 packages/
#   apk-git  仓库里提交的 .apk（固定 commit）  → packages/
#   bin-tar  Release 附件，是 tar.gz           → 取出指定文件放进镜像（不归 apk 管理）
# 升级：改 tag/commit/文件名，sha256 用 `gh release view <tag> -R <repo> --json assets` 里的 digest，
# 或下载后 `sha256sum`。
